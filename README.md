Welcome to the Naya Operating System project! Naya is a lightweight, efficient, and secure operating system designed for educational purposes and experimental use. This project aims to provide a foundational understanding of operating system concepts, including process management, memory management, file systems, and more.

## Project Goals

The primary goals of the Naya Operating System project are:

- [ ] **Modularity:** Design an operating system with a modular architecture that allows easy addition and modification of components.
- [ ] **Documentation:** Provide comprehensive documentation that aids in understanding and contributing to the project.

## Features

Naya OS includes the following features:

- [ ] **Process Management:** Basic scheduling and process control.
- [ ] **Memory Management:** Simple memory allocation and paging.
- [ ] **File System:** Support for basic file operations and storage management.
- [ ] **Device Drivers:** Basic drivers for common hardware components.
- [ ] **User Interface:** Command-line interface (CLI) for interacting with the OS.
- [ ] **Networking:** Basic networking stack for communication.

- QEMU or another virtual machine for testing
